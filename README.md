# ことば帳

学校の単語テスト向けに、回・範囲ごとの単語帳を作り、英単語または古文単語を学習するWebアプリです。

## 初回のSupabase設定

現在は本番公開前のローカル動作版です。Supabaseの無料プロジェクトを1つ作成してから、次の順番で設定します。

1. [Supabase Dashboard](https://supabase.com/dashboard) で新しいプロジェクトを作成します。
2. 左側の「SQL Editor」→「New query」を開きます。
3. このフォルダの `supabase-schema.sql` をメモ帳で開き、内容をすべてコピーしてSQL Editorへ貼り付け、「Run」を押します。
4. Supabaseの「Authentication」→「URL Configuration」を開き、Site URLを `http://127.0.0.1:8766/` にします。Redirect URLsにも同じURLを追加します。
5. Supabaseの「Project Settings」→「API」を開きます。
6. このフォルダの `Supabaseを設定する.bat` をダブルクリックし、画面の案内に従ってProject URLとPublishable keyを貼り付けます。旧画面の場合はanon keyを使用できます。
7. `起動する.bat` をダブルクリックします。

`service_role` key、Secret key、データベースのパスワードは入力しないでください。設定補助画面も、明らかな秘密鍵は拒否します。

## アカウントと使い方

1. 初回は「新規アカウント」でメールアドレスと6文字以上のパスワードを登録します。
2. Supabase側でメール確認が有効な場合は、届いた確認メールのリンクを開いてからログインします。
3. 「単語帳」タブから、名前と種類（英単語／古文単語）を指定して単語帳を作成します。
4. 単語帳を選択して、「単語を編集」タブから単語を追加します。
5. 「テスト」タブで単語帳とテスト方式を選択して学習します。
6. 自己判定で「覚えてない」を選んだ単語は、その単語帳の「復習」タブに追加されます。

### テスト範囲の選び方

- 「固定範囲」では、全単語または25語ごとの範囲をワンタップで選べます。
- 「開始・終了」では開始番号と終了番号を別々に入力でき、「範囲を追加」で複数範囲をまとめられます。重複する番号は1語として数えます。
- 「番号を選択」では番号ボタンをタップします。「すべて選択」「すべて解除」「選択を反転」も利用できます。
- 出題数は選択操作のたびに更新されます。番号は単語帳の上から順に数えます。

ログイン状態はブラウザに保持されます。別の端末で同じアカウントにログインすると、Supabaseに保存された同じ単語帳を読み込む構成です。本番公開前のため、iPhone・iPadから実際にアクセスするには、次の段階でHTTPS対応の公開先が必要です。

既存版の単語帳がブラウザ内に残っており、ログイン先のクラウドが空の場合は、初回ログイン時に移行確認が表示されます。「OK」を選ぶと、そのアカウントへ一括移行します。

## データ構成と安全対策

- `notebooks`: 単語帳名、英単語／古文単語の種類、所有ユーザー
- `words`: 見出し語、意味、メモ、正解候補、所属単語帳、所有ユーザー
- `review_items`: 「覚えてない」の復習対象、所属単語帳、所有ユーザー
- 3テーブルすべてでRow Level Security（RLS）を有効化し、ログイン中の `auth.uid()` と `user_id` が一致する行だけを読み書きできます。
- 単語と復習対象には、親の単語帳と同じユーザーでなければ関連付けられない複合外部キーがあります。
- 保存用RPCは `security invoker` で動作し、RLSを回避しません。
- ブラウザにはProject URLとPublishable keyだけを置きます。`service_role` keyは使用しません。
- 単語帳・単語・復習対象は1回の保存処理でまとめて同期されます。

## 通常の起動方法

`起動する.bat` をダブルクリックしてください。ブラウザで `http://127.0.0.1:8766/` が開きます。

- Python・Node.jsのインストールは不要です。
- `index.html` は直接開かないでください。画像OCRに必要なブラウザ機能が安全上ブロックされます。
- 起動中は黒い画面を閉じず、終了するときはその画面で `Ctrl + C` を押してください。

## 画像から単語帳を作る

1. 「画像から作成」タブを開きます。
2. 単語帳名と種類を入力し、「単語表の画像を選択」を押します。複数画像を選べます。
3. 「画像を読み取る」を押し、表示される読み取り状況を待ちます。
4. 黄色の「要確認」が付いた行は、見出し語・意味を修正するか「確認済みにする」を押します。手動で修正した行は「修正済み」になり、再びOCR判定へ戻りません。
5. すべて確認したら「この内容で単語帳を作成」を押します。

OCRの文字認識はブラウザ内で実行されます。英語・日本語の言語データはアプリのフォルダ内に置いてあります。初回はOCRプログラム本体の取得にインターネット接続が必要です。

### 対応する単語表

- 主な対象は、`No. | 見出し語（英単語） | 意味（日本語）` の3列表です。
- 2ページが横並びの画像は、自動で左右に分割します。
- 表の範囲・横罫線・列位置を検出し、No.列を除いて英単語欄と意味欄を別々に読み取ります。
- 初回結果の文字・信頼度を自動評価し、怪しいセルだけ拡大率・コントラスト・罫線除去・ページ分割モードを変えて再読み取りします。
- 日本語欄は二値化を主候補に使わず、原画像の濃淡を残した約280～340px高の複数画像で、日本語向けOCRを行います。
- 通常より高いセルは複数行向けOCRで読み、No.と英単語が空欄で意味だけが続く行は直前の単語へ結合します。
- `【】`、`≪≫`、`（）`、丸数字、`/` はOCR評価でノイズ扱いせず、最初の語義を切り出すまで保持します。
- 複数の結果は、文字の自然さ・OCR信頼度・候補同士の一致度を合成して比較し、最も信頼できる候補だけを確認画面に表示します。
- 複数画像も選択できます。意味は最初の語義だけを候補に残します。
- 再読み取り後も候補が一致しない、文字が小さい、信頼度が低い行だけを「要確認」にします。
- 確認画面では元画像の該当行を表示します。状態は「OK」「要確認」「修正済み」「確認済み」に分かれます。

## 保存について

- 登録した単語帳、単語、正解候補、復習リストは、ログイン中ユーザーのSupabaseデータベースへ保存されます。
- 右上が「クラウド保存済み」になれば保存完了です。エラー時は画面上に内容を表示します。
- 「バックアップ」から、その時点のデータをJSONファイルとして保存できます。
- 以前のlocalStorageデータは移行元としてだけ読み、以後の変更はlocalStorageへ保存しません。
